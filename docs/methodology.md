# 计算口径

## 时点与比较

按报告截止日比较相邻期末，发布日期单独保留。只有截止日和发布日期不晚于查询时点的记录才能参与比较。同一截止日优先使用持仓披露范围更完整的报告。基金经理采用报告或明确任期证据；当前页面显示的经理不自动代表历史管理人。

季度前十披露并不等于全部持仓。新出现/消失的证券分别标为进入/退出披露名单，只有完整持仓表才支持期末无持仓判断。持股数量变化不直接证明买卖，送转股、配股等公司行为仍需核对；仓位变化也受价格和申赎影响。共同管理产品保留所有经理，不归因到某一人。

## 价格参考

使用两个披露时点之间未复权日线最低 low 和最高 high，显示起止日、实际观测起止、记录数、币种和源。此区间仅是期间可能成交价格的参考，无法还原存量持仓的买入成本或交易时间。港股行情以 HKD 表示，报告持仓市值通常以 CNY 表示，两者不直接相乘。缺失或不完整行情不得宣称完整区间或真实成本。

## 持仓金额

优先取报告披露市值，另计算同一报告期的基金资产净值 × 占基金资产净值比例 ÷ 100。不能使用今天的规模、总资产或占股票资产的权重代替。A/C 等份额属于同一投资组合时去重，不重复加总；不同组合及不同报告期不合并为单一总资产。缺少规模时仅保留报告市值。

## 报告逻辑

仅展示有来源的报告策略段落或短摘录，并标注报告覆盖期。中报策略覆盖半年，不能默认解释第二季度每笔交易；整体行业观点也不能推断为每只股票的交易理由。完整原文通过源链接查阅。

PDF 先在 Actions runner 内存中处理，不进入 `web/data`。配置 `MINER_U_KEYS`、`MINER_U` 或 `MINERU_API_KEY` 时，解析器按 MinerU v4 的批量接口申请上传 URL、上传 PDF、轮询结果并读取 zip 内的 `full.md`；MinerU 的页标记用于保留原始页码。没有密钥或服务返回固定失败码时，自动回退到有界的 pypdf 文本层解析。两条路径都输出解析方法、文本哈希、页面统计、原文策略摘录、主题和 PDF 来源页码；失败不会把空结果当作已解析。

## 覆盖与更新

当前固定研究 2026Q2：持仓日为 2026-06-30、比较基准为 2026-03-31，信息截止日为 2026-09-29。目录覆盖公开机构清单，逐家发现其基金，再由 Actions 分批计算。清单机构数不是已完成研究数，产品份额数也不是去重后投资组合数。

页面展示实际成功基金数、机构数、持仓数、价格和策略覆盖率、错误分类及抓取时间。目录未映射、待处理、已获取持仓、报告明确无股票、失败各自保留。失败时保留上一份有效观察且标明继承；缺失数据不补造。持仓、行情、净值、季报策略分别统计覆盖，持仓抓取成功不代表所有字段齐全。
