# 计算口径

## 时点与比较

按报告截止日比较相邻期末，发布日期单独保留。只有截止日和发布日期不晚于查询时点的记录才能参与比较。同一截止日优先使用持仓披露范围更完整的报告。基金经理采用报告或明确任期证据；当前页面显示的经理不自动代表历史管理人。

查询截止日、公告日期和成立日期按中国自然日（Asia/Shanghai）解释；观测时间保留原始带时区字符串，先后次序仍按真实时点比较。历史查询参数及已冻结批次的查询日期不会随午夜变化，下一轮默认查询才采用新的中国日期。

季度前十披露并不等于全部持仓。新出现/消失的证券分别标为进入/退出披露名单，只有完整持仓表才支持期末无持仓判断。持股数量变化不直接证明买卖，送转股、配股等公司行为仍需核对；仓位变化也受价格和申赎影响。共同管理产品保留所有经理，不归因到某一人。

## 价格参考

使用两个披露时点之间未复权日线最低 low 和最高 high，显示起止日、实际观测起止、记录数、币种和源。此区间仅是期间可能成交价格的参考，无法还原存量持仓的买入成本或交易时间。港股行情以 HKD 表示，报告持仓市值通常以 CNY 表示，两者不直接相乘。缺失或不完整行情不得宣称完整区间或真实成本。

季度行情以交易所公开休市安排生成应有交易日集合，逐日核对实际记录；仅有首尾日期或记录数量相同不足以通过。缺日、额外日期、异常记录及来源冲突分别保留，未核实的新股上市、停牌或退市不自动豁免。独立来源已经完整时优先采用该来源；多个部分来源只在证券、币种、价格口径一致且同日价格不冲突时合并。本期及相邻上期披露过的股票都纳入价格补采，部分行情仍可查看，但不计入完整区间。

美股报价保留 USD，核验证券代码、美国交易所、时区和币种；同一股票的类别代码保留原报告写法及标准化代码。来源可能调整拆股历史价格时，未能排除公司行动影响的观察不作为未复权区间。QDII 跨页持仓表按原 PDF 单元格位置提取；同一发行人下多类证券共享排名时，排名组数与证券行数分别核验。

## 持仓金额

优先取报告披露市值，另计算同一报告期的基金资产净值 × 占基金资产净值比例 ÷ 100。不能使用今天的规模、总资产或占股票资产的权重代替。A/C 等份额属于同一投资组合时去重，不重复加总；不同组合及不同报告期不合并为单一总资产。缺少规模时仅保留报告市值。

## 报告逻辑

仅展示有来源的报告策略段落或短摘录，并标注报告覆盖期。中报策略覆盖半年，不能默认解释第二季度每笔交易；整体行业观点也不能推断为每只股票的交易理由。完整原文通过源链接查阅。

策略章节完整度与观点选摘分别记录：核对“投资策略和运作分析”的起止标题、连续物理页、报告标题对应的季度及文本哈希，截断或仅有一段文字不算整节完整。完整文本仅在解析内存中使用，公开结果保留句子分类计数、最多八条短引文、页码与来源。市场回顾、组合操作表述、后市展望按明确措辞归类且可重叠；这些分类不是全文语义理解的完成证明。证券全名或代码的明确提及单独标注，不自动推断为具体交易或调仓原因。

新增解析结果在同一季度来源内共用引文池：最多八条、每条一百六十个 Unicode 码点、合计一千二百八十个码点。摘录、叙述和规则证据仅引用池内同一段文字；额度按唯一来源引文计，不按 JSON 中兼容字段重复序列化的字节计。旧无池观察继续保留原文和原时间，单列待迁移，不能据此取得新解析的完整状态。

有限规则扫描覆盖完整策略章节中的所有分句，分别保留已识别、无法确定、选摘和未展示的计数。明确主语、对象、语气、时间及原文位置通过校验才接受；引用他人观点、否定范围不清或多重含义保留未知。同句明确原因也只表示报告的组合层面表述，不证明某位经理对某只股票的交易动机。章节完整、规则扫描完成、全文语义解读验收是三个状态；七项采集证据齐全不能替代语义解读验收。

新观点来源保留真实 PDF 获取时点、文件身份、章节与文本哈希。相同季度同源同文的补充分析可以单独归并，旧持仓、经理及行情的观测时点不刷新；新 PDF 获取时点与旧策略观测时点分别保存。方法与来源摘要不因重复获取时间变化而重置。

基金经理从报告中明确的任职表提取，保留任职日、离任日、职务、页码与原文证据；共同管理者分别保留。二季度优先采用对应季报经理表，中报回退仅保留任期与 4–6 月重叠的经理。当前资料、任期重叠推定与报告表格证据分开，只有最后一类计入新增的“报告经理”完整度字段。

经理完整度还要求整张经理表的起止章节、连续物理页及全部候选行均可核对。缺日期、漏行、截断或不明行只保留有效姓名并标记部分，不把首位经理解析成功当作完整名单。经理表与持仓表可以来自不同报告，分别绑定原 PDF、公告日期、覆盖期和文本哈希；期内离任经理与期末仍在任经理分开展示。

PDF 先在 Actions runner 内存中处理，不进入 `web/data`。配置 `MINER_U_KEYS`、`MINER_U` 或 `MINERU_API_KEY` 时，解析器按 MinerU v4 的批量接口申请上传 URL、上传 PDF、轮询结果并读取 zip 内的 `full.md`；只有明确的原始页标记才能建立页码引用，没有页标记时显示“页码未核验”。没有密钥或服务返回固定失败码时，自动回退到有界的 pypdf 文本层解析，另记原文件页数、已处理页数、截断状态和文本质量。两条路径都输出解析方法、文本哈希、原文策略摘录和主题；失败或文本不足不代表整份 PDF 已解析。

## 覆盖与更新

跨基金分析以所选季度全部已保留观察为输入，完整索引已观察证券。只有来源明确证明组合主代码及份额归属、且机构归属没有冲突的组合才参与金额加总；其他记录保留明细并标注身份待核验。披露市值与同日净资产乘权重分别求和，缺值不补零。股票行情按币种与季度观察窗口核验，报告人民币市值不与外币股价直接混算。观点仅保留本季度报告短摘录、页码及来源，主题是规则归类，不能据此推断该股票的具体交易动机。

PDF 持仓表只有在完整文件已处理、章节起止明确、单位可确认、表格行序连续且没有漏行或不支持证券时，才解除“可能截断”标记。持仓表 PDF 证据与经理观点 PDF 证据分别保留，中报的完整表格不会因为引用同截止日季报观点而失去来源。未满足这些条件的表格继续标为待补。

2026Q2 的持仓日为 2026-06-30、比较基准为 2026-03-31；2026Q3 的持仓日为 2026-09-30、比较基准为 2026-06-30。两个季度分别保存结果、进度和缺失项，信息截止日按本轮采集记录。网页按季度选择，只加载所选季度；新季度尚无结果时，不以旧季度数据替代。目录覆盖公开机构清单，逐家发现其基金，再由 Actions 分批计算。公司归属尚未匹配的产品也进入采集。清单机构数不是已完成研究数，产品份额数也不是去重后投资组合数。

个别公司目录刷新失败时，保留其旧核验归属并显示原核验日期及“沿用缓存归属”；本次主目录获取日期不代表这些公司已同日重新核验。仍保留历史已核验产品代码，未匹配机构的产品继续按代码采集。

当前在售目录不能证明报告期历史范围完整：季末仍存续、其后清盘或合并的产品可能已从当前名单消失。各季度将当前目录与具有明确截止日的历史来源分别核对，并把计划使用的季度名单与发布结果绑定到同一份摘要。历史文件读取成功、所有有效行解析成功、产品及份额范围核验完成、研究字段齐全是不同状态；历史范围未完成核验时，即使全部已知代码已有结果，也不宣布全行业采集或分析完成。

历史产品索引中的主代码不等于全部份额代码。PDF 的“基金主代码”和明确列出的份额交易代码另存为报告级凭证，核对报告期间、公告日期、原文件哈希、实际页码和代码行；基期、季报及中报各自保存，不能互相覆盖来源。它只能证明报告明确列出的代码，不证明全部历史份额已找齐。

已核验历史索引的成立日期可以补充无法读取的当前概况，但仅适用于该来源行对应的产品代码。成立日期落在基准期末之后、目标期末之前时，可有据说明该产品不存在对应基准期报告；不会把主代码的成立日转给其他份额。来源日期冲突时不作豁免；只有日期、来源而没有对应行及文件凭证的历史索引引用也不作豁免。

页面展示实际成功基金数、机构数、持仓数、价格和策略覆盖率、错误分类及抓取时间。目录未映射、待处理、已获取持仓、报告明确无股票、失败各自保留。失败时保留上一份有效观察且标明继承；缺失数据不补造。持仓披露表、PDF 文本、季报策略、净资产、精确上期基准和行情分别核验；缺项进入独立补采队列。重试用完仍是未完成，工作流成功不代表研究完整。报告明确无股票的产品保留其 PDF 和运作说明，不凭基金类型推断无持仓。

研究完整度现另含报告经理，共七项；另保留不含经理的六项基础字段齐全数，均按当前校验计算。行情及基准验证要求已收紧，不能将新版计数与旧版直接比较。旧记录缺少经理证据时，进入有独立尝试次数的补采队列。资产负债表的股票投资金额为零，必须由同一物理页的表名、报告截止日、本期末与上年度末列及明确双零股票行共同证明，界面标作“期末股票投资账面金额为零”，不据此推断季度内没有交易。若上期有已核验股票披露，继续保留其退出名单状态，不补造本期股数或卖出时间；本期期末无股票也不能替代相邻基准报告。

批次时间预算结束前尚未启动请求的产品，单独显示“本批未轮到”，保留原来的状态与尝试次数，不新增一次抓取失败。这个延期数量可能与产品原有的待处理或失败状态重叠，不能直接相加为目录总数。只有实际请求后未取得有效结果，才记入相应失败分类。

当日可执行批次耗尽时，自动续跑可以结束，但研究状态仍保持未完成。若存在 `nextRetryAt`，页面显示“本轮结束，等待复查”以及按北京时间展示的最早复查时间；实际执行仍取决于后续定时任务。Q3 的 2026-11-30 是本项目补采观察窗口配置，不是季报的法定披露期限；窗口结束仍缺失的数据不会被改记为齐全。

有公开来源明确证明成立日期晚于目标季度期末的产品，单独记为“期后成立，不适用”，保留日期与来源。它们不计入持仓、无股票持仓或研究字段齐全数量；研究完整度以本季度适用产品为分母。未找到报告本身不能证明产品期后成立。

报告期末前已经终止的产品，另凭原始公告中的明确终止事实、最后运作日或终止日及基金代码认定季末不适用；条件性终止提示、销售渠道终止及缺少报告均不能作为证据。终止记录保留在目录中，不抹去季度内活动。清算报告期结束日只表示该报告覆盖期间，不能解释为清算款项已全部支付。

参考：[证监会信息披露管理办法](https://www.csrc.gov.cn/csrc/c106256/c1653985/content.shtml)、[2026 年定期报告准则](https://www.csrc.gov.cn/csrc/c101954/c7619929/content.shtml)。

同一证券及季度的全部已存完整区间，若具有完整东方财富原始区间锚点，可以独立分类其端点数值：Yahoo 端点必须与锚点精确相等，或严格等于锚点转换为 IEEE 754 binary32 后的值。两个不同的完整东方财富区间，即使落入同一 binary32 数值桶，也继续记为来源冲突；未知来源的不同数值和未解释的局部极值同样保留待核验。参考区间采用已有完整东方财富原值，原始报价、来源、采集时间和冲突见证不被此分类覆盖。该分类只说明已存季度最低价、最高价的数值表达兼容，不声称逐日行情相同或逐次原始响应已复验；价格区间仍不是实际持仓成本。
